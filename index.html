LAB 01

Blinking an LED using Arduino Uno

Digital Output Embedded Demo
lab01_led_blink.mp4 Recorded Demo
Objective: Configure a digital I/O pin on the Arduino Uno as an output and toggle an external LED at fixed time intervals.

Components Used

Arduino Uno, 5mm LED, 220 Ω resistor, solderless breadboard, male-to-male jumper wires.

Working Principle

The microcontroller alternates pin 13 between HIGH (5V) and LOW (0V) with a 1-second pause between state transitions.
led_blink.ino 
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
}

void loop() {
  digitalWrite(ledPin, HIGH); // Turn LED ON
  delay(1000);                // Wait 1 second
  digitalWrite(ledPin, LOW);  // Turn LED OFF
  delay(1000);                // Wait 1 second
}

Observation: Placing a 220 Ω resistor in series protects the LED from excess current. Adjusting the delay() duration directly modifies the blink frequency.

LAB 02

Potentiometer Brightness Control with Arduino

Analog Input · PWM Embedded Demo
lab02_potentiometer.mp4 Recorded Demo
Objective: Read continuous analog voltage levels from a 10 kΩ potentiometer and map them to smooth LED brightness via Pulse Width Modulation (PWM).

Components Used

Arduino Uno, 10 kΩ rotary potentiometer, LED, 220 Ω resistor, breadboard, jumper wires.

Working Principle

analogRead() samples the wiper voltage as a 10-bit integer (0–1023), which map() scales to an 8-bit PWM duty cycle (0–255) on pin 9.
potentiometer_pwm.ino 
const int potPin = A0;
const int ledPin = 9; // PWM-capable pin

void setup() {
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  int rawValue = analogRead(potPin);            // 0 to 1023
  int pwmLevel = map(rawValue, 0, 1023, 0, 255);
  analogWrite(ledPin, pwmLevel);
  Serial.println(rawValue);
  delay(50);
}

Observation: Rotating the shaft smoothly varies both the Serial Monitor readings and the perceived luminosity of the LED without visible flicker.

LAB 03

Distance Measurement with HC-SR04 Ultrasonic Sensor

Spatial Sensing Embedded Demo
lab03_ultrasonic_sensor.mp4 Recorded Demo
Objective: Measure real-time object proximity in centimeters using an HC-SR04 ultrasonic transceiver and trigger an alert LED when an obstacle is within 10 cm.

Components Used

Arduino Uno, HC-SR04 ultrasonic module, alert LED, 220 Ω resistor, breadboard, jumper wires.

Working Principle

A 10 µs trigger pulse emits 40 kHz sound waves. pulseIn() records the echo round-trip time to compute one-way distance.
ultrasonic_rangefinder.ino 
const int trigPin = 9;
const int echoPin = 10;
const int ledPin  = 13;

void setup() {
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  long duration = pulseIn(echoPin, HIGH);
  float distanceCm = (duration * 0.0343) / 2.0;
  Serial.println(distanceCm);

  digitalWrite(ledPin, distanceCm < 10.0 ? HIGH : LOW);
  delay(200);
}

Observation: Flat, rigid surfaces reflect clean echoes, while crossing below the 10 cm threshold reliably switches the indicator LED ON.

LAB 04

Wireless Bluetooth Control via HC-05 Module

Wireless Serial Embedded Demo
lab04_bluetooth_control.mp4 Recorded Demo
Objective: Establish a wireless UART bridge between an Android smartphone and Arduino Uno using an HC-05 Bluetooth module to toggle hardware remotely.

Components Used

Arduino Uno, HC-05 Bluetooth transceiver, LED, 220 Ω resistor, smartphone with Bluetooth terminal app, jumper wires.

Working Principle

Single-character commands ('1' or '0') transmitted over Bluetooth are parsed via SoftwareSerial to switch pin 13.
bluetooth_switch.ino 
#include <SoftwareSerial.h>

SoftwareSerial btSerial(2, 3); // RX, TX
const int ledPin = 13;

void setup() {
  pinMode(ledPin, OUTPUT);
  btSerial.begin(9600);
}

void loop() {
  if (btSerial.available()) {
    char command = btSerial.read();
    if (command == '1') digitalWrite(ledPin, HIGH);
    if (command == '0') digitalWrite(ledPin, LOW);
  }
}

Observation: Cross-connecting TX to Arduino pin 2 and RX to pin 3 (with voltage division on RX for 3.3V logic safety) keeps wireless commands responsive at 9600 baud.

Android Calculator App in MIT App Inventor

Objective: Build a functional four-operation Android calculator using MIT App Inventor to master event-driven UI components and conditional validation.

Core Features

Dual numeric input fields, operator buttons (+, −, ×, ÷), dynamic output label, and division-by-zero protection.

Working Principle

Each button click fires an event handler that parses both text fields, executes the arithmetic block, and updates the display label.
calculator_blocks.txt 
when AddButton.Click
  set ResultLabel.Text to (Number1.Text + Number2.Text)

when DivideButton.Click
  if Number2.Text = 0 then
    set ResultLabel.Text to "Cannot divide by zero"
  else
    set ResultLabel.Text to (Number1.Text / Number2.Text)

Observation: Adding an explicit check for Number2 = 0 prevents runtime crashes and demonstrates defensive UI programming.
